# 个人博客简明使用手册

## 本地预览

在项目根目录打开 PowerShell。首次使用先运行 `npm ci`，之后运行：

```powershell
npm run dev -- --host 127.0.0.1 --port 5173
```

浏览器打开 <http://127.0.0.1:5173/web_self/>。结束预览时在 PowerShell 按 `Ctrl+C`。如果遇到端口 `EACCES`，换一个没有被 Windows 保留的端口。

## 添加文章

在 `src/content/posts/` 新建英文文件名，例如 `my-first-note.md`。复制下面的模板，再替换内容：

```markdown
---
title: 我的文章标题
description: 用一句话概括文章。
date: 2026-11-02
category: 学习笔记
tags: [编程, 学习]
sample: false
draft: false
---

## 正文标题

在这里写文章内容。
```

分类只支持「学习笔记」「生活随记」「建站记录」。把 `draft` 改为 `true` 可暂存草稿；改回 `false` 后会加入文章列表。文件名会成为文章网址的一部分。保存后本地预览会自动更新。

## 在文章中展示代码

用三个反引号包住代码，并在开头写语言名称：

````markdown
```js
const greet = (name) => `你好，${name}！`;
console.log(greet('世界'));
```
````

语言可写 `js`、`html`、`css`、`python` 等。

## 更换头像

将新头像转换为 WebP，并保存为 `public/images/avatar.webp`，覆盖原文件即可。头像在首页与“关于”页共用，圆形裁切位置由 `src/styles/global.css` 中 `.avatar` 的 `object-position` 控制。

## 保存到 GitHub

先构建确认文章和页面能生成：

```powershell
npm run build
git add src/content/posts/my-first-note.md
git commit -m "Add my first note"
git push origin main
```

把示例文件名换成自己的文章文件。只暂存本次要提交的文件；本项目根目录的 `index.html` 是旧文件，当前 Astro 博客首页由 `src/pages/index.astro` 生成。文章推送到 `main` 后，`.github/workflows/astro.yml` 会自动构建并发布 `dist/`。首次部署需在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
