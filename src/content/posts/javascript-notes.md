## 从一个具体问题出发

假设有一组文章标题，需要在每个标题前加上编号。我们可以用循环，也可以用数组的 `map` 方法。

```js
const titles = ['第一篇手记', '一个小项目', '本周回顾'];
const numbered = titles.map((title, index) => `${index + 1}. ${title}`);
console.log(numbered);
// ['1. 第一篇手记', '2. 一个小项目', '3. 本周回顾']
```

## map 做了什么

`map` 会依次取出原数组中的每个元素，把它交给一个函数，再把函数返回的值放进新数组。它本身不会替换原数组，但回调函数仍然可能修改对象元素，因此不要把它简单理解为“任何情况下都没有副作用”。

这里的 `title` 是当前标题，`index` 是从零开始的下标。因为给人看的编号通常从一开始，我们加上了 `1`。
