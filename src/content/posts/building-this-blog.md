## 先从真正需要的东西开始

一个个人博客，最重要的能力是写文章、读文章，以及让读者认识作者。第一版可以很小：一个首页、一个文章列表、几个项目和一页自我介绍。

这篇示例借助当前博客的实际结构，解释如何从一个简单网页走向可维护的静态网站。

## 为什么选择 Astro

HTML 和 CSS 仍然是基础。Astro 在它们之上提供了组件和页面组织方式，让导航、页脚和页面框架只需要维护一次。

构建时，Astro 把模板和 Markdown 文章生成 HTML 文件。因此，读者打开页面时，不需要先下载一套完整的前端应用才能看到文章。

> 先让内容有一个稳定的家，再考虑增加更多功能。

### 一个共享的页面框架

`src/layouts/Base.astro` 负责公共导航、网页标题和页脚。页面只需要把自己的内容放在这个框架里。

```astro
---
import Base from '../layouts/Base.astro';
---
<Base title="关于">
  <h1>你好，我是 vilcg。</h1>
</Base>
```

### 文章是内容，不是页面代码

文章放在 `src/content/posts/` 中。文件开头的 frontmatter 描述标题、日期和分类，后面写 Markdown 正文。

内容集合会检查这些字段，缺少标题或使用未知分类时，构建会报告错误。这能帮助我们尽早发现写作时的小疏漏。

## 给第一版设定边界

这一版暂不加入评论、账号系统和数据库。它们各自有价值，但也会带来维护成本。等真实的使用需求出现，再决定引入什么工具。
