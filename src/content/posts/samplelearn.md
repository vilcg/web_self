# AIMA 第四版第 19 章学习笔记：从样例中学习

## 本篇重点：19.7 非参数学习（以 k 近邻为主）

> 这份笔记按课程对话整理。**课堂已讲**部分只记录历史对话中确实出现的内容；**补充说明**用于补齐概念背景，不代表课堂已经讲授。课程记录里实际练习的是 k 近邻（k-NN）的水果分类。AIMA 第四版 19.7 还包含其他主题，本篇不把它们写成已学内容。[AIMA 第四版目录](https://aima.cs.berkeley.edu/contents.html)

## 1. 课堂已讲：k-NN 在做什么

我们有一些已经标好类别的训练水果，以及一个尚未分类的新水果。每个水果用两个数表示特征：甜度和脆度，写作坐标 `(甜度, 脆度)`。k-NN 的基本做法是：

1. 计算新水果到每个已知水果的距离。
2. 按距离从近到远排列，选出最近的 `k` 个样本。
3. 让这 `k` 个邻居按类别投票，票数最多的类别就是预测结果。

`k` 表示参与投票的近邻数量。`k=1` 时只采用最近一个样本的类别；`k=3` 时看最近三个样本的多数票。

## 2. 课堂已讲：欧氏距离

两个二维样本 $P=(x_1,y_1)$ 和 $Q=(x_2,y_2)$ 的欧氏距离是：

$$
d(P,Q)=\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}
$$

直观上，这是坐标平面上两点之间的直线距离。距离越小，两个水果在这两个特征上越接近。若每个样本有 `n` 个特征，公式推广为：

$$
d(P,Q)=\sqrt{\sum_{j=1}^{n}(p_j-q_j)^2}
$$

### 水果例子一：手算距离并分类

课堂给出的样本如下：

| 样本 | 坐标（甜度，脆度） | 类别 |
|---|---:|---|
| A | (2, 7) | 苹果 |
| B | (8, 3) | 橙子 |
| C | (4, 6) | 苹果 |
| D | (4, 7) | 未知水果 |

先计算 A 到 D 的距离：

$$
d(A,D)=\sqrt{(2-4)^2+(7-7)^2}=\sqrt{4}=2
$$

再算 C 到 D：

$$
d(C,D)=\sqrt{(4-4)^2+(6-7)^2}=\sqrt{1}=1
$$

B 到 D 的距离为：

$$
d(B,D)=\sqrt{(8-4)^2+(3-7)^2}=\sqrt{32}=4\sqrt{2}\approx5.66
$$

所以从近到远是 **C、A、B**，距离依次为 **1、2、约 5.66**。

- `k=1`：最近邻是 C，类别为苹果，因此预测 D 是苹果。
- `k=3`：三个样本中有两个苹果、一个橙子；多数票是苹果，因此仍预测苹果。

令 $N_k(x)$ 表示距离待预测样本 $x$ 最近的 $k$ 个训练样本的索引集合。分类规则写作：

$$
\hat y(x)=\operatorname{mode}\{y_i\mid i\in N_k(x)\}
$$

其中，`mode` 表示出现次数最多的类别；$x_i$ 是第 $i$ 个训练样本，$y_i$ 是它的已知类别，$\hat y(x)$ 是模型给出的预测类别。若最高票数并列，还需要另定平票处理规则。

## 3. 课堂已讲：改变 k 会改变预测

后续课程使用了**另一组 7 个水果样本**：4 个苹果、3 个橙子。其中一个标成橙子的样本被刻意放进苹果附近，作为标签噪声的例子。

| 坐标 | 类别 | 说明 |
|---:|---|---|
| (2, 7) | 苹果 | 训练样本 |
| (3, 7) | 苹果 | 训练样本 |
| (2, 6) | 苹果 | 训练样本 |
| (3, 6) | 苹果 | 训练样本 |
| (8, 3) | 橙子 | 训练样本 |
| (8, 4) | 橙子 | 训练样本 |
| (2.5, 6.7) | 橙子 | 人为加入的噪声标签 |

课程对话展示的观察结果：

| 待预测位置 | `k=1` | `k=3` | `k=7` |
|---|---|---|---|
| 苹果附近 `(2.6, 6.8)` | 橙子 | 苹果 | 苹果 |
| 橙子附近 `(8.1, 3.5)` | 橙子 | 橙子 | 苹果 |

怎么理解：

- 苹果附近的点在 `k=1` 时被最近的噪声样本带偏，预测成橙子；扩大到 `k=3` 后，最近的三个样本中苹果占多数，结果变成苹果。
- 橙子附近的点在 `k=3` 时，附近的橙子邻居占多数；当 `k=7` 时所有训练样本都参与投票，整体上苹果有 4 票、橙子有 3 票，因此预测苹果。
- 这个例子说明，`k` 改变后，同一数据和同一待预测点可能得到不同分类结果。

## 4. 课堂已讲：k 与过拟合、欠拟合的直觉

- **k 太小的倾向：** 决策容易受局部样本影响，对噪声或错标样本敏感。`k=1` 的例子中，苹果附近的新水果就被噪声标签误导。这是过拟合的直观风险：把训练数据里的偶然细节也当成规律。
- **k 太大的倾向：** 投票范围变大，局部差异可能被整体类别比例掩盖。7 个样本全部参与时，无论新水果靠近苹果还是橙子，都会被判成苹果。这是欠拟合的直观风险：模型过于平滑，重要的局部规律也被忽略。
- **目标是泛化：** 训练样本上的表现好，不一定意味着对没见过的新样本预测也好。课程提到实际选择 `k` 时要比较验证集表现；验证集的具体流程属于后续内容。

课堂的核心关系可以概括为：

| k 的大小 | 常见表现倾向 | 需要留意的风险 |
|---|---|---|
| 较小 | 更关注局部，边界可能复杂 | 对噪声敏感、过拟合 |
| 适中 | 在局部细节和整体趋势间折中 | 需要根据数据判断 |
| 较大 | 边界更平滑，依赖更广范围的样本 | 忽略局部差异、欠拟合 |

这描述的是倾向，不是保证。合适的 `k` 取决于数据。

## 5. 算法步骤（回顾）

给定带标签的训练集 $D=\{(x_i,y_i)\}$、待预测样本 $x$ 和邻居数 $k$：

```text
对训练集中的每个样本 xᵢ：计算距离 d(x, xᵢ)
按距离从小到大排序
取前 k 个样本
统计这 k 个样本各类别的票数
返回票数最多的类别
```

分类任务里的 k-NN 不需要先拟合一条直线或一组固定系数；预测时要查找并比较训练样本。这是课堂例子中可以直接观察到的算法流程。

## 6. Python 初学者版：实现课堂的七样本例子

下面只用 Python 标准库。代码对应课程给出的水果坐标和类别；`sqrt` 计算平方根，`sorted` 按距离排序，`[:k]` 取最近的 k 个样本。

```python
from math import sqrt

data = [
    ((2, 7), "苹果"),
    ((3, 7), "苹果"),
    ((2, 6), "苹果"),
    ((3, 6), "苹果"),
    ((8, 3), "橙子"),
    ((8, 4), "橙子"),
    ((2.5, 6.7), "橙子"),  # 课堂例子中的噪声标签
]

def distance(point_a, point_b):
    dx = point_a[0] - point_b[0]
    dy = point_a[1] - point_b[1]
    return sqrt(dx ** 2 + dy ** 2)

def predict(new_fruit, k):
    # 每项为（距离，类别）
    ranked = []
    for point, label in data:
        ranked.append((distance(new_fruit, point), label))

    ranked.sort()  # 默认先按距离从小到大排列
    nearest = ranked[:k]

    apple_votes = 0
    orange_votes = 0
    for _, label in nearest:
        if label == "苹果":
            apple_votes += 1
        else:
            orange_votes += 1

    if apple_votes > orange_votes:
        return "苹果"
    if orange_votes > apple_votes:
        return "橙子"
    return "平票"

apple_area = (2.6, 6.8)
orange_area = (8.1, 3.5)

for k in [1, 3, 7]:
    print(
        "k =", k,
        "苹果附近：", predict(apple_area, k),
        "橙子附近：", predict(orange_area, k),
    )
```

预期输出：

```text
k = 1 苹果附近： 橙子 橙子附近： 橙子
k = 3 苹果附近： 苹果 橙子附近： 橙子
k = 7 苹果附近： 苹果 橙子附近： 苹果
```

## 7. 易错点

1. **把 k 当成类别数。** `k` 是近邻的数量，不是要分类的类别数量。
2. **只找最近的一个。** 只有 `k=1` 才只看最近样本；`k=3` 要统计最近三个样本的类别。
3. **距离算完后没有排序。** 选近邻之前，必须按距离从小到大排列。
4. **坐标顺序不一致。** 甜度和脆度应始终按同一顺序记录；比较两点时，每个特征要和对应特征相减。
5. **平方后忘记开根号。** 欧氏距离是平方差求和后再开平方。若只比较谁更近，平方距离的排序相同；但报告欧氏距离时要开根号。
6. **把两组水果数据混在一起。** A/B/C/D 是手算距离的小例子；四苹果三橙子的 7 点数据是研究 k 影响的另一例子。
7. **以为 k 越大越好。** k 太大时可能抹平附近的类别结构，课堂中 `k=7` 的结果就展示了这种情况。

## 8. 补充说明（非课堂已讲）

### 8.1 “非参数”是什么意思？

参数模型通常用数量固定的一组参数概括训练数据，例如一条直线的斜率和截距。非参数模型不要求模型只能由固定数量的参数描述；k-NN 会保留训练样本，预测新样本时再根据这些样本寻找近邻。因此它也常被称为基于实例或基于记忆的方法。这里是概念补充，课程记录尚未正式讲解“参数模型/非参数模型”的定义。

### 8.2 距离与特征尺度

欧氏距离会直接受数值范围影响。如果一个特征的数值范围远大于另一个特征，它可能主导距离计算。真实任务中常要考虑标准化或其他特征缩放方法；这不在目前的课程记录中。

### 8.3 平票、k 的选择和 19.7 的范围

- 若类别票数相同，算法需要额外的平票处理规则。示例代码显式返回“平票”。
- 二分类时常选奇数 `k` 来降低平票机会，但奇数 k 不能解决所有多分类平票问题。
- 课程提到用验证集比较不同 `k`，但具体划分、准确率计算和测试集使用流程还没有在这段对话中讲授。
- AIMA 第四版目录把 k-d 树、局部敏感哈希、非参数回归、支持向量机和核技巧也列在 19.7 下。本篇只按课程已出现的内容展开 k-NN，不将这些主题写成已学知识。[AIMA 第四版 19.7 目录](https://aima.cs.berkeley.edu/contents.html)

## 9. 少量重点自测

### 题 1：距离与投票

对未知水果 `D=(4,7)`，已知 `A=(2,7)` 是苹果、`C=(4,6)` 是苹果、`B=(8,3)` 是橙子。三个距离分别是多少？若 `k=3`，预测哪一类？

<details>
<summary>查看答案</summary>

$d(A,D)=2$，$d(C,D)=1$，$d(B,D)=\sqrt{32}\approx5.66$。三个邻居中苹果两票、橙子一票，所以预测苹果。

</details>

### 题 2：k 的影响

在七样本例子中，为什么 `k=1` 时苹果附近的新水果会被分成橙子，而 `k=3` 时会变成苹果？

<details>
<summary>查看答案</summary>

最近的单个样本是被错标为橙子的噪声点；取三个邻居时，邻居投票中苹果占多数，噪声的影响被抵消。

</details>
